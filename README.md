  Coheteros US Ground Station
</h3>

#### Installation

Install npm packages:

```bash
npm install
```

Install Python packages:

```bash
cd backend
setup.bat
```

#### Usage

Start backend:

```bash
cd backend
activate.bat
python fake.py
```

Start frontend:

```bash
npm run build
npm run preview
```

#### Development

Start backend:

```bash
cd backend
activate.bat
python fake.py
```

Start frontend:

```bash
npm run dev
```
